⚠️ Warning: This is a Batch (.bat) program created for a simple “Guess the Number” game. The program randomly selects a number from 1 to 150, and the player tries to guess it. Based on the entered number, the program displays “LOWER” or “HIGHER”. After guessing the correct number, pressing A starts a new game, while pressing N exits the program.

Safety: This script does not install software, delete files, or modify system settings. It is intended only for entertainment and learning the basics of Batch programming.
